# Dropdown Header Images

Place your dropdown header images in the category folders below.

## 📁 Folder Location

**Full Path:** `frontend/public/assets/images/menu/`

## 📂 Folder Structure

```
frontend/public/assets/images/menu/
├── skincare/
│   └── header.jpg  (or .png)
├── makeup/
│   └── header.jpg  (or .png)
├── hair/
│   └── header.jpg  (or .png)
├── fragrance/
│   └── header.jpg  (or .png)
└── body/
    └── header.jpg  (or .png)
```

## 📝 Image Naming

**Important:** Name your images exactly as: **`header.jpg`** (or `header.png`)

The images will automatically appear at the top of each dropdown menu when you hover over the category in the navigation.

## ✅ How to Add Images

1. Navigate to: `frontend/public/assets/images/menu/`
2. Open the category folder (e.g., `skincare`, `makeup`, etc.)
3. Drop your image file and name it `header.jpg` (or `header.png`)
4. The image will automatically appear in the dropdown!

## 🖼️ Supported Formats

- JPG/JPEG
- PNG
- WebP

## 💡 Note

If an image is not found, it will automatically hide (no broken image display).
