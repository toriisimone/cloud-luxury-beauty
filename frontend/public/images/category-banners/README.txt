Place your category page banner images in this folder.

Supported filenames (JPG or PNG):
- skincare-banner.jpg / skincare-banner.png
- makeup-banner.jpg / makeup-banner.png
- hair-banner.jpg / hair-banner.png
- fragrance-banner.jpg / fragrance-banner.png
- body-banner.jpg / body-banner.png

Banner text is NOT baked into images; the category name is overlaid by the UI.
Images render with object-fit: cover, so 1440×808 will not distort (cropping only).
